# 덕담 번역

잔소리 → 덕담 단방향 번역기. 서버가 OpenAI Responses API의 `gpt-5-nano`를 호출합니다. 브라우저는 API 키를 받지 않습니다.

## 설정과 실행

Node.js 20.12 이상이 필요하며 별도 패키지 설치는 없습니다.

1. OpenAI API 키를 발급합니다: https://platform.openai.com/api-keys
2. 프로젝트의 `.env` 파일에서 `OPENAI_API_KEY=` 뒤에 키를 입력합니다. 파일이 없다면 `.env.example`을 `.env`로 복사합니다.
3. `npm run dev` 실행 후 http://localhost:3000 에서 이용합니다. 포트를 바꾸려면 `npm run dev -- --port 3017`을 사용합니다.
4. 키를 추가·변경한 뒤 서버를 재시작합니다. 배포 환경에서는 `.env` 대신 서버의 비밀 환경 변수 `OPENAI_API_KEY`를 설정합니다.

`.env`는 Git에서 제외되고 HTTP로 제공되지 않습니다. 키를 채팅, 프런트엔드 코드, 저장소에 넣지 마세요. API 키는 서버 시작 시에만 읽습니다. 브라우저에는 HTML, CSS, app.js만 제공합니다.

## 동작과 비용

- 방향과 모델은 서버에서 고정합니다. 사용자가 방향, 프롬프트 또는 모델을 바꿀 수 없습니다.
- 입력을 1.1초 멈추거나 Enter를 누르면 번역합니다. 한국어 조합 중에는 요청하지 않습니다.
- 음성은 브라우저 Web Speech API로 인식하고, 확정된 텍스트만 번역 API에 보냅니다. 읽어주기도 브라우저 기능을 사용합니다.
- `gpt-5-nano`, 최소 추론, 짧은 출력, 최대 출력 512토큰(추론 포함), `store: false`를 사용합니다. 불완전한 응답은 번역 결과로 표시하지 않습니다.
- 입력은 최대 300자이며 서버 전체에서 분당 최대 30회의 새 API 요청, 동시 요청 최대 3개로 제한합니다. 자동 재시도는 없습니다.
- 최근 결과 100개를 서버 메모리에 최대 10분간 재사용합니다. 같은 탭에서도 결과를 재사용합니다. 입력이 바뀌면 대기 중인 요청을 취소하고 오래된 응답을 표시하지 않습니다. 취소 전에 처리된 토큰에는 비용이 발생할 수 있습니다.
- 저장한 번역은 localStorage, 현재 탭의 기록은 sessionStorage에 보관합니다.
- 키 미설정·한도·시간 초과·연결 실패는 오류로 표시합니다. 예시 번역으로 대체하지 않습니다.

2026-09-24 공식 일반 요금 기준 `gpt-5-nano`는 100만 토큰당 입력 $0.05, 출력 $0.40입니다. 추론 토큰도 출력 비용에 포함됩니다. 실제 요청당 비용은 사용량에 따라 다릅니다.

기본 서버는 로컬(127.0.0.1)에서만 열립니다. 외부 서비스로 배포할 때는 HTTPS와 이용자 인증 또는 서비스에 맞는 접근·사용량 제한을 추가하세요. 현재 프로세스 단위 요청 제한은 사용자 인증이나 총 예산 제한을 대신하지 않습니다.

## 검증

`npm run check`와 `npm test`를 실행합니다. 서버 테스트는 OpenAI 응답을 모의 처리해 실제 키나 API 비용 없이 입력 검증, 단방향 설정, 비밀 파일 차단, 결과 재사용과 실패 처리를 확인합니다. 실제 모델의 한국어 품질과 계정 접근 권한은 키 설정 후 별도로 확인해야 합니다.

- 모델: https://developers.openai.com/api/docs/models/gpt-5-nano
